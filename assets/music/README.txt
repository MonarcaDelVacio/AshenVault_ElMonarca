ASHEN VAULT - MUSICA

Coloca aqui las cuatro pistas de musica.

Nombres recomendados (preferiblemente .ogg):
  MenuPrincipal.ogg
  MusicaDefault no batlle.ogg
  Batallas (Sin Jefes).ogg
  BossFight.ogg

Tambien se prueban automaticamente estas extensiones:
  .ogg, .mp3, .wav, .flac, .m4a

IMPORTANTE:
pygame-ce documenta soporte para WAV, MP3, OGG, FLAC, OPUS, WV y formatos MOD/MIDI.
M4A no aparece en la lista oficial de formatos soportados, por lo que no se recomienda
usar .m4a para la version jugable. Si tus archivos actuales son M4A, conviertelos a
OGG Vorbis manteniendo estos mismos nombres. No hace falta modificar el codigo.

Las pistas se reproducen automaticamente en bucle mientras permanezca su contexto.
No necesitas editar los audios para hacerlos loop.


FALLBACK INCLUIDO
Si no se proporcionan pistas externas, el proyecto incluye pistas WAV procedurales de respaldo con estos mismos nombres. Puedes reemplazarlas por tus pistas definitivas (preferiblemente OGG) conservando los nombres.
