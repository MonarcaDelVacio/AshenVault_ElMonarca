ICONOS DE ASHENVAULT

Coloca aquí:
- AshenVaultIcon.png  -> icono maestro 1:1 con fondo transparente. Se usa en la ventana del juego.
- AshenVaultIcon.ico  -> versión Windows para el futuro .exe, accesos directos e instalador.

El PNG recomendado es de alta resolución (por ejemplo 1024x1024).
El ICO debería contener varios tamaños (16, 32, 48, 64, 128 y 256 px).
