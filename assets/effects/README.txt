AshenVault - Efectos de combate
================================

Coloca aqui los PNG de efectos nuevos:

Corte melee:
  cortearmameleeframe1.png ... cortearmameleeframe6.png

Explosion:
  explosionframe1.png ... explosionframe8.png

Proyectil igneo:
  proyectiligneoframe1.png ... proyectiligneoframe6.png

Congelacion:
  congelado.png

Los archivos son opcionales para iniciar el juego, pero para ver estos efectos
deben estar presentes con esos nombres exactos.

El corte y el proyectil se orientan automaticamente hacia su direccion.
La explosion cambia de tamano segun el radio del impacto.
El hielo se muestra semitransparente sobre cualquier entidad congelada.
