AshenVault - Enemy Assets

Los sprites de esta carpeta se cargan automáticamente según el campo
"sprite_set" de cada enemigo en data/enemies.json.

Tipos añadidos:
- arcane_acolyte -> esbirromago
- gargoyle -> Gargola
- stone_golem -> Minigolem + Proyectilrocadelgolem
- undead_swordsman -> Nomuerto
- undead_knight -> Nomuerto2
- ice_monkey -> Monodehielo
- ogre -> Ogro
- giant_minotaur -> Minotaurogigante

Los sprites que ya contienen el arma dentro del dibujo no reciben un arma
adicional del sistema de armas. Los proyectiles de fuego usan el efecto
proyectiligneoframe1..6; los ataques melee usan cortearmameleeframe1..6.
